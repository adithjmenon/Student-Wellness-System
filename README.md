# Student Health and Wellness Management System

## Project Overview

The Student Health and Wellness Management System is a Python console application. It helps students store their basic details, calculate BMI, record daily wellness habits, and view a wellness report.

This project was created using basic Python concepts such as functions, lists, dictionaries, loops, conditional statements, file handling, JSON, and modules.

## Features

- Add student details
- View saved student details
- Prevent duplicate student IDs
- Calculate BMI and show BMI category
- Add daily wellness records
- Record water intake, sleep hours, exercise minutes, and mood
- View wellness records and averages
- Delete student records
- Save data using a JSON file

## Technologies Used

- Python
- JSON file handling
- Visual Studio Code

## Project Modules

- `main.py` - Displays the menu and connects all features
- `database.py` - Loads and saves student data
- `health_calculator.py` - Calculates BMI and BMI category
- `student_manager.py` - Adds, views, checks, and deletes students
- `wellness_tracker.py` - Adds and reads wellness records
- `reports.py` - Displays the wellness report
- `data.json` - Stores saved student data

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Type python3 main.py.
4. Press Enter.
5. Choose an option from the menu.
