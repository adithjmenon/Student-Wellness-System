# Project Statement

## Project Title

Student Health and Wellness System

## Problem Statement

Students may not keep track of their daily health habits such as drinking water, sleeping, and exercising. It can be difficult to remember this information every day.
This project helps students save their basic details and daily wellness information in one place.

## Project Objective

The objective of this project is to create a simple Python program that can store student health details and show a basic wellness report.

## Target Users

The target users are college students who want to track their basic health and wellness habits.

## Scope of the Project

This project can:

- Add student details
- View student details
- Calculate BMI
- Add water intake, sleep hours, exercise minutes, and mood
- Show a wellness report with average values
- Delete student details
- Save information in a JSON file

## Main Features

1. Student Management  
   The user can add, view, and delete student details.

2. BMI Calculator  
   The user can calculate BMI using height and weight.

3. Daily Wellness Tracker  
   The user can save water intake, sleep hours, exercise minutes, and mood.

4. Wellness Report  
   The user can view saved wellness records and average values.
